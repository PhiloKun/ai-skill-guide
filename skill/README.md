# AI Skill 说明文档（总览）

> 本目录是一套**讲解文档**，用 Markdown 系统说明：AI 的 Skill 是什么、有什么用、如何编写，以及进阶功能与排错。
> 内容基于 CodeBuddy 内置的 `skill-creator` 规范与真实内置技能（`SKILL.md`、初始化 / 校验 / 打包脚本）整理。

---

## 30 秒速览

| 问题 | 一句话答案 |
| --- | --- |
| Skill 是什么 | 一个以 `SKILL.md` 为核心、可附带脚本 / 参考资料 / 模板的**自包含能力包**，相当于给 AI 的「岗位 SOP + 工具箱」。 |
| 解决什么问题 | 通用模型不知道你的私有流程、规范和领域细节；Skill 把这些知识按需注入，且不必每次粘贴一大段提示词。 |
| 怎么生效 | 靠 `name` + `description` 被 AI 语义匹配到 → 加载 `SKILL.md` 正文 → 按需读取附带资源，即「渐进式披露」。 |
| 怎么写 | 收集真实用例 → 规划 `scripts/` `references/` `assets/` → 初始化目录 → 写 `SKILL.md` → 校验 / 打包 → 实测迭代。 |
| 还有什么能力 | 用户级 / 项目级作用域、可执行脚本、按需加载的长文档、输出模板、自动校验、zip 分发、触发词调优、与 Rules / MCP 协作。 |

## 一图看懂结构

```text
skill-name/                      # 目录名 = frontmatter 里的 name
├── SKILL.md                     # 必需：YAML frontmatter + Markdown 指令
│   ├── name:                    # 必需，hyphen-case，如 release-notes
│   └── description:             # 必需，决定「什么时候被触发」
├── scripts/                     # 可选：可执行的确定性代码
│   └── collect_commits.py
├── references/                  # 可选：按需加载进上下文的长文档
│   └── format.md
└── assets/                      # 可选：不进上下文、直接用于产出的文件
    └── template.md
```

加载顺序（渐进式披露）：

```text
① name + description    常驻上下文（约 100 词）
        ↓ 语义命中用户请求
② SKILL.md 正文         触发时加载（建议 < 5k 词）
        ↓ 正文引用到的资源
③ scripts / references / assets   按需加载或直接执行
```

## 重要说明

1. **本目录不是可直接加载的 Skill**。它是一组讲解用的 `.md` 文件，没有 `SKILL.md` 所需的结构。
2. 若要让 AI 真正使用，须创建含 `SKILL.md` 的技能目录，并放到以下位置之一：
   - 用户级：`~/.codebuddy/skills/<skill-name>/`（跨所有项目可用）
   - 项目级：`<项目>/.codebuddy/skills/<skill-name>/`（随仓库共享给协作者）
3. 作用域不确定时优先选**用户级**；只有需要团队共享规范、schema、流程时才用项目级。
4. 文档中的命令示例以 macOS / CodeBuddy CN 内置路径为例，其他环境请替换脚本路径。
